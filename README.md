# ⚙️ Prerequisites

Before running the projects, make sure you have:

- Java 17+
- Maven Installed
- MySQL Installed
- STS / IntelliJ IDEA
- Git Installed

---

# ▶️ Clone Repository

```bash
git clone https://github.com/abhishekkargeti1/SpringBoot-Project-.git
```

---

# ▶️ Run The Project

Navigate to the required project folder and run:

```bash
mvn spring-boot:run
```

Or run the main Spring Boot application class directly from STS / IntelliJ IDEA.

---

# 🔑 Database Configuration

Update your database credentials inside:

```properties
application.properties
```

Example:

```properties
spring.datasource.url=jdbc:mysql://localhost:3306/database_name
spring.datasource.username=root
spring.datasource.password=your_password

spring.jpa.hibernate.ddl-auto=update
spring.jpa.show-sql=true
```
